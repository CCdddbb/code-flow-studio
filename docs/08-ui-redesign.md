# 工作台 UI 重设计

## 目标

将营销展示页式的界面改为适合阅读代码、核对流程的工具界面。移除大标语、荧光配色、渐变、装饰性英文栏目和过多的大型卡片。不新增分析能力，也不改变 v0.2 的安全分享边界。

## 开源参考

已查阅以下开源项目的 README 和设计体系入口：

- [GitHub Primer React](https://github.com/primer/react)：参考开发工具的信息组织、侧栏、工具栏、边框和状态表达；[设计文档](https://primer.style/react)。
- [shadcn/ui](https://github.com/shadcn-ui/ui)：参考克制的组件形态、间距、表单、Tabs 与 Dialog；[组件文档](https://ui.shadcn.com/docs)。
- [Primer CSS](https://github.com/primer/css)：用于了解体系。该仓库目前说明处于 KTLO，因此没有把它作为新运行依赖。

这里是设计参考，不是声称使用了以上组件库。页面仍采用原生 HTML/CSS/ES Modules，未复制完整组件、品牌或模板，未安装 React/Tailwind，也没有引入远程字体、图标或 CDN。简单 SVG 图标在本项目内编写。保留此实现方式是为了单文件离线导出和现有安全校验。

## 设计变化

| 原界面 | 新界面 |
| --- | --- |
| 深色荧光绿、大字号标语 | 浅色工作区、黑灰文字、蓝色操作强调 |
| 首页式 Hero 与巨大指标卡 | 项目标题、行内统计、紧凑工具栏 |
| 质量面板占据首屏 | 可展开的分析摘要，未解析数量始终可见 |
| 装饰性侧栏 | 真实文件列表、可定位的流程步骤 |
| 大圆角渐变容器 | 4–6px 圆角、细边框、表格式字段/关系 |
| 大量英文口号与特殊字符图标 | 中文任务标签、统一线性 SVG |
| 控件只有鼠标交互 | Tabs 方向键/Home/End、焦点提示、跳过导航链接 |
| 窄屏侧栏直接消失 | 可展开导航，Escape 收起 |

### 信息层级

1. 顶栏：当前位置、导入、JSON 与安全导出。
2. 左栏：示例项目、当前分析文件、步骤定位；没有伪造历史项目。
3. 项目头：标题、语言、文件/函数/步骤/未解析数量。
4. 折叠摘要：静态分析的用途、证据引用与全部节点依据。
5. 主工作区：流程 / 数据转换 / 源码证据。
6. 流程页：三段关系、播放器、调用关系表与诊断。

依据色仅用于小面积状态标识，继续同时显示文字，避免将“推断”“未知”和“模拟”混淆为已执行结果。

## 实现与兼容

- 重写 `public/index.html`、`public/style.css`。
- `public/app.js` 增加真实文件/步骤导航、Tab 键盘导航、移动端导航和紧凑摘要。
- 原有导入、分析、JSON 编辑、三种分享策略、风险确认和离线不可升级逻辑保持不变。
- 新生成模型的 `presentation.theme` 为 `light`；Schema 继续接受历史 `midnight` 值以兼容旧模型。当前渲染器采用新版浅色界面，不提供主题切换器。
- 未改动外部草稿箱 Demo。版本与仓库更新见 [更新日志](../CHANGELOG.md)。
