# v0.3 第一阶段：参考场景实验室

## 状态与边界

版本：`0.3.0-alpha.1`。这是 v0.3 的模型/渲染验证切片，不代表整版路线图完成。

新增场景不来自源码分析，也未读取原业务仓库或旧 Demo。两个案例均在本仓库独立编写：草稿提交与恢复、订单与消息交付。每个案例包含成功、拒绝、失败/结果未知、恢复四类路径。公开示例中的键、记录、条件与存储名称均为合成值。

## 用户任务

用户可以逐步核对：当前状态如何变化、哪个逻辑存储发生什么变化、回执丢失后是否仍可能存在业务记录，以及跨存储窗口为什么不应画成整体强事务。第二个业务案例复用相同运行器和 DOM 渲染逻辑，不需要草稿专用页面。

## 模型与实现

- `schema/scenario.schema.json`：独立 `scenario-1.0.0` Schema，不扩展或覆盖源码分析和安全分享 Schema。
- `public/scenarios.js`：公开参考模型、纯模拟运行器、语义校验。
- `src/scenarios.js`：Ajv 严格结构校验和语义校验入口；返回独立模型副本。
- `public/app.js`：参考案例/路径选择、步骤导航、状态变化、存储 Before/After、操作清单、事务边界及假设来源。

模型包括 `states`、`transitions`、`stores`、`scenarios`、`transactionRegions`、`assumptions`。快照由显式变化推导，不保存第二份可漂移的快照数据。允许的变化只有单记录顶层字段 `set`、`unset`、`increment`，不模拟 SQL/MongoDB 引擎、真实插入删除或事务回滚。

条件只是作者为路径提供的说明。运行器根据明确指定的迁移 ID 检查状态连续性，不求值文本、调用用户函数或解释源码。路径从相同初始状态/记录开始；重复运行确定，不修改模型、其他路径或先前步骤快照。

校验拒绝：重复 ID、无效引用、终态外出迁移、路径不连续、未知操作、非数值递增、非有限数值、危险原型字段及过深嵌套。事务原子性字段仅允许 `unverified`，多存储边界明确展示“不得视为单一强事务”。

## 来源与分享

所有模型和步骤固定为 `authored-assumption`，**不冒充 `source` 或 `user-confirmed`**。假设保留作者与修订号，尚不提供用户确认、编辑或完整修订历史。

场景 UI 明确显示与当前源码项目无关联，不计入质量摘要、源码事实或证据覆盖率。分析 JSON 仍只有原有分析/分享模型；不会夹带当前场景选择、模拟快照或用户临时输入。

单文件 HTML 把公开参考目录与运行器作为应用资源内联，三种分享级别均可离线体验相同参考场景。这不是还原原分析中的字面量；导出清单明确说明 HTML 内置独立公开案例。原有源码白名单重建、确认门禁与离线不可升级披露级别的机制不变。

没有新增网络请求、依赖、模型服务或数据库访问。现有用户源码不会发送至外部服务。

## 本地验收

- `npm run verify`：63 个 Node 测试通过，其中新增 13 个参考场景测试。
- `npm run test:browser`：21 项检查通过，其中新增 4 项场景交互/窄屏检查；Java/TypeScript × 三种离线导出模式均实际运行恢复场景。
- 覆盖：版本冲突无存储写入、回执未知不虚构回滚、恢复不重复业务写入、版本递增与 unset、非法迁移、深拷贝/确定性/不可变目录、第二案例泛化。
- 保留：安全分享、源码注入、原静态流程、投影、键盘导航、390px 窄屏及无外部请求回归。
- 截图：`docs/images/studio-scenarios.png`。

上述是本地验收，不代表远程 CI 已运行或已发布 Release。
