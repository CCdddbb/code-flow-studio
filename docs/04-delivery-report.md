# v0.1.0 交付与迭代报告

## 交付定位

一个可运行、可上传 GitHub 的本地静态代码分析与可视化项目。它把源码事实和有限数据投影变成通用工作台，不是对任意工程进行完整语义还原的系统。

原有草稿箱 Demo 仅作为交互设计参考；没有复制内部业务源码、证据摘录、数据库配置或运行记录。公开示例全部为新写的合成代码。

## 实际迭代记录

### 第一轮：打通生成闭环

完成源码输入、TS AST、Java 词法适配、中间模型、静态调用展开、三栏装配台、数据投影、CLI 与离线导出。

初次命令行检查暴露 Ajv 严格模式的 union type 配置问题，修复后成功生成两种语言示例。

### 第二轮：测试驱动修正

完成 Node 测试与真实浏览器回归。发现并修复：

- 空格目录被 URL pathname 编码为 `%20`，测试路径错误；改用 fileURLToPath。
- Java record 被词法模式误当作方法；增加排除规则。
- 返回局部 const 变量时血缘停在变量名；增加受限别名追溯。
- 使用 fetch 验证 Host header 的测试没有真实覆盖恶意 Host；改为原生 HTTP 请求核验。
- 增加 Java 显式字段声明类型的静态连接，同时标明不证明 Spring 注入。

独立 HTML 经 file:// 打开验证，不依赖启动服务器或 ES Module 导入。

### 第三轮：真实性与发布收尾

- 有副作用的初始化会阻断后续模拟，避免声称输入未被修改。
- 检查嵌套作用域与参数遮蔽，防止错误匹配同名函数。
- Java 注解线索排除注释中的假注解。
- 脱敏应用到解析输入与生成表达式，不只是展示摘录。
- 新增证据核验命令、Schema 与跨引用门禁。
- 补充安全说明、MIT、贡献文档、CI、可手动运行的 Pages 合成演示。
- 项目固定公开 npm registry，避免本机默认私有 registry 影响审计/复现。
